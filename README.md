I'm a software developer based in the south of the United Kingdom. I mainly work with C# and .NET professionally, but enjoy working with different languages, technologies and hardware in my spare time.

Most of my personal projects start with something I want to use myself or a problem I've created for myself.

### Projects

**[WatchHistory for YouTube™](https://ytwatchhistory.com/)**

A browser extension that tracks your YouTube watch history locally in your browser and brings back some of the functionality lost when you disable YouTube's watch history.

I originally built it because I was fed up with getting distracted by YouTube Shorts on my phone. Turning off my YouTube watch history stopped Shorts from loading, but also meant losing some useful features. I'd often want to go back to a video I'd watched, only to find I couldn't remember what it was called, or I'd find it again and have no idea where I'd left off.

So I built a browser extension to replace some of the functionality I'd deliberately disabled. It started out fairly basic and gradually grew from there.

**[Pi Server Remote](https://github.com/GeorgeElliott/pi-server-remote-rust)**

A lightweight web dashboard for managing my home server, including waking it using Wake-on-LAN, checking its status and running commands remotely.

It runs on a Raspberry Pi 1 Model A that had been sitting in a box for the last 12 years.

I originally wrote the application in Python, but it was using around 20% of the Pi's available memory. I rewrote it in Rust to see if I could reduce that, eventually getting memory usage down to around 5%.
